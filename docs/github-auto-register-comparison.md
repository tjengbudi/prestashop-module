### Catatan Free AI Router

1. **9router (22k⭐)** = paling populer, 40+ providers, RTK token savings -40%
2. **OmniRoute (17k⭐)** = paling lengkap, 231+ providers, MCP/A2A, Desktop PWA
3. **freellmapi (16k⭐)** = ~4B tokens/month, 28 providers, encrypted keys
4. **AIClient2API (8k⭐)** = multi-protocol (OpenAI+Claude+Gemini), provider pools
5. **freerouter** = ada beberapa fork: freerouter/freerouter (BYOK), openclaw-freerouter, BMajnu/FreeRouter
6. **Strategi:** Router ini menggabungkan free tier dari 20-40+ provider → satu endpoint
7. **Total ~4B tokens/month** bisa didapat dari semua free tier combined
8. **Auto-fallback** = kunci utama: ketika satu provider rate-limit, otomatis pindah ke provider lain
9. **Token savings** = RTK (Redundant Token Killing) bisa hemat 15-95% tokens
10. Semua project untuk **learning & research** — perhatikan ToS masing-masing provider
